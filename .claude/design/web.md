# 화면 설계

`cuesheet/web`의 화면 결정만 담는다. 스택 선택은 [stack.md](stack.md), 도메인은 [cuesheet.md](cuesheet.md).

화면은 `cuesheet_get` 응답 하나로 전부 그린다. 클라이언트 상태는 없다.

---

## 위치

| 경로 | 내용 |
|---|---|
| `cuesheet/web/index.html` | 뷰 마크업. 이미 있다 |
| `cuesheet/web/app.css` | 손으로 쓴 CSS. 아직 없다 |
| `cuesheet/web/app.js` | 폴링·렌더·카운트다운. 아직 없다 |

`api/` 안에 두지 않는다. [rules/api/server.md](../rules/api/server.md)가 `server/`를 도메인 무지 어댑터로 한정한다 — 화면 자산은 어댑터가 아니다. `bin/server.py`가 `Frontend(path="/", directory="cuesheet/web")`로 이미 등록한다.

---

## URL

해시 라우팅이다. 주소가 화면 상태의 단일 출처이고, 새로고침·뒤로가기·링크 공유가 전부 된다.

| 주소 | 화면 |
|---|---|
| `#/` | 세션 없으면 로그인·가입, 있으면 큐시트 선택 |
| `#/c/{cuesheet_id}` | 큐시트 — 눈금 축 + 미니맵 + 진행 조작 |
| `#/join/{token}` | 초대 링크 (아직 미구현) |

큐시트를 열면 바로 축이 나온다. 진행 조작·상태·지연도 같은 화면에 있다 —
"내 다음 큐" 요약만 있는 중간 화면을 두지 않는다.

경로 라우팅(`/c/{id}`)을 쓰지 않는다. 정적 마운트가 미지의 경로에 index.html 을 내려주지 않아
(`fallback`을 `index.html`로 줘도 404) 서버에 catch-all 라우트를 따로 만들어야 하는데,
그러면 `/app.css` 같은 정적 파일보다 먼저 잡혀 순서를 손으로 관리해야 한다.

`/c/` 접두사는 API 의 `/cuesheets` 와 겹치지 않게 고른 것이다. 예쁜 주소가 필요해지면
catch-all 라우트 하나로 바꾸고 `shell/route.js` 의 `go`/`current` 만 고치면 된다.

## 뷰

`index.html`의 기존 뷰 구성을 유지한다. 갈아엎지 않는다 — 로그인·가입·큐시트 선택은 이미 도메인과 맞고, 새로 설계한 타임라인이 들어갈 자리는 그중 하나다.

| 뷰 | 언제 |
|---|---|
| login | 세션 없음 |
| register | login에서 가입 |
| pick | 세션 있고 큐시트 미선택 |
| run | 큐시트 선택됨 |
| timeline | run에서 전체 큐시트 열기 |

`timeline`은 기존 `<details>` "전체 큐시트"를 승격시킨 것이다. 미니맵 레일이 고정 높이 스크롤 컨테이너를 전제하는데, 인라인 `<details>` 안에서는 페이지 스크롤과 내부 스크롤이 겹쳐 레일이 무엇을 가리키는지 무너진다.

### 큐시트 화면의 구성

제목·상태·지연 → 축(스크롤) + 레일 → 진행 조작 → 연결 상태.
축이 화면의 대부분을 차지하고 나머지는 그 위아래에 붙는다.

레일이 고정 높이 스크롤 컨테이너를 전제하므로 축 영역은 `flex: 1` 로 늘린다 —
그리드 행 번호로 잡으면 숨은 형제 하나에 배치가 통째로 밀린다.

---

## timeline — 눈금 축

원칙 하나: **블록 높이 = 실제 소요시간.** 왼쪽에 시간 눈금, 블록은 축에 절대 위치로 붙어 여백이 없다.

| 항목 | 값 | 이유 |
|---|---|---|
| 배율 | 1분 = 46px | 3분 무대 블록에 제목·역할·시간이 들어가는 최소 |
| 눈금 간격 | 2분 | 46px 간격이면 라벨이 안 겹친다 |
| 눈금 라벨 | 절대 시각 (`20:04`) | 큐시트가 절대 시각으로 운용된다 |
| 블록 사이 | 0 | 여백을 주면 비율이 틀어진다 |
| 짧은 큐 | 최소 높이 보장 | 제목·길이가 잘리면 블록이 정보를 잃는다. 늘어난 블록은 `≈` 로 표시하고, 그만큼 뒤를 밀어 겹침을 막는다 |
| 현재 시각 | 축 좌측 배지 + 가로 점선 | 눈금 라벨과 같은 열에 놓여 그 값으로 읽힌다 |

배율은 고정한다. 프로그램 길이에 맞춰 자동 축소하면 90분 행사에서 30초 큐가 2px가 된다 — 전체 조망은 레일이 맡는다.

## 미니맵 스크롤바

전체 조망을 화면 오른쪽 끝 스크롤바 자리로 옮긴다. 축을 둘 두면서도 폭을 나눠 쓰지 않는다.

| 항목 | 값 |
|---|---|
| 폭 | 10px 고정 |
| 터치 영역 | 20px. 시각 폭과 무관 |
| 트랙 | 큐시트 전체를 컨테이너 높이에 압축. 큐당 세그먼트 하나, 사이 1px |
| 세그먼트 평소 | opacity 0.4 |
| 세그먼트 조작 중 | opacity 1.0. 전환 0.2초 |
| 복귀 지연 | 0.9초 |
| thumb | 테두리 없음. 흰색 30% → 조작 중 40%. 최소 높이 24px |
| 네이티브 스크롤바 | 숨긴다 |

폭은 조작 중에도 변하지 않는다 — 레일이 넓어지면 본문 오른쪽을 가리고 시선이 레일로 끌려간다. 필터가 벗겨지는 것만으로 상태 변화는 전달된다.

현재 시각은 레일에 표시하지 않는다. 축과 레일 양쪽에 같은 표시가 있으면 어느 쪽을 봐야 하는지 흐려진다.

### 상호작용

| 동작 | 결과 |
|---|---|
| 본문 스크롤 | thumb 이동 + 필터 해제 |
| 레일 드래그 | 해당 구간으로 이동 |
| thumb 밖 탭 | 그 지점으로 점프 |

## 테마

라이트·다크 둘 다 지원한다. 기본은 시스템 설정(`prefers-color-scheme`)이고, `data-theme` 속성이 있으면 그것이 이긴다.

행사장은 어둡지만 준비 단계는 사무실에서 한다 — 한쪽만 만들면 나머지 절반의 작업 시간이 눈부시다.

포인트 색은 blue, 중립은 slate. 팔레트는 Tailwind v4 OKLCH 값을 그대로 쓴다.

다크는 라이트의 미러가 아니다. 라이트에서 accent가 blue-700(어두운 파랑 + 흰 글자)인데 같은 값을 다크에 쓰면
버튼이 배경과 2.96밖에 안 떨어져 가라앉는다. 다크는 **밝은 파랑 + 어두운 글자**로 뒤집는다.

| | 라이트 | 다크 |
|---|---|---|
| accent | blue-700 | blue-500 |
| accent-ink | white | slate-950 |
| hover | blue-800 (어둡게) | blue-400 (밝게) |

두 테마 모두 글자 대비 4.5:1 이상, 버튼과 배경의 분리 3:1 이상을 확인했다.
다크에서 카드를 그리는 것은 배경이 아니라 테두리다 — raised와 surface의 차이는 1.13에 불과하다.

## 색

큐가 자기 색을 가진다. `Cue.color` 는 원시 색값이 아니라 **팔레트 키**다 —
`slate` `blue` `teal` `amber` `rose` `violet` 여섯 개.

hex 를 저장하지 않는 이유: 라이트에서 읽히는 색이 다크에서 안 읽힌다. 키를 저장하고
테마별 실제 색은 `token/cue.css` 가 정하면, 색 하나가 두 테마 모두에서 성립한다.

색과 담당 여부는 축이 다르다.

| 축 | 출처 | 표현 |
|---|---|---|
| 큐 종류 | `cue.color` | 색상(hue) |
| 담당 여부 | 큐의 task 중 `me.role_ids`에 걸린 것이 있는가 | 진하기 — 담당 아니면 opacity 0.4 |
| 진행 상태 | `current_cue_id` | 현재 큐에 outline |

역할별 색은 쓰지 않는다. `Role`은 행사마다 자유 추가라 색 수가 가변이다.
색은 큐가 갖고, 역할은 담당 여부(진하기)로만 드러난다.

## 좌표

축과 레일이 같은 변환 하나를 공유한다.

| | 기준점 | 배율 |
|---|---|---|
| 본 축 | 축 시작 시각 | 46px / 분 (고정) |
| 레일 | 축 시작 시각 | 컨테이너 높이 / 전체 소요시간 |

블록 위치는 `eta`, 높이는 `planned_sec`에서 나온다. 클라이언트가 시각을 누적하지 않는다 — 서버가 `eta`를 이미 계산해 내려주므로 두 곳에서 같은 산술을 하면 어긋난다.

## 데이터 매핑

`cuesheet_get` 응답만으로 전부 그린다.

| 화면 요소 | 필드 |
|---|---|
| 축 블록 위치 | `cues[].eta` |
| 축 블록 높이 | `cues[].planned_sec` |
| 블록 제목 | `cues[].title` |
| 블록 색 | `cues[].color` |
| 담당 여부 | `cues[].tasks[].role_id` ∩ `me.role_ids` |
| 현재 큐 | `cuesheet.current_cue_id` |
| 현재선 위치 | `cuesheet.cue_started_at` + 로컬 경과 |
| 지연 배지 | `cuesheet.delay_sec` |
| 카운트다운 목표 | 현재 큐의 `eta` + `planned_sec` |
| manager 여부 | `me.can_advance` |
| 종료 상태 | `cuesheet.ended_at` |

### eta가 없는 큐

진행 중에는 서버가 현재 큐부터만 `eta`를 채우고 지난 큐는 `null`로 준다. 축은 현재 큐에서 시작하고, 지난 큐는 축 위에 개수만 접어 둔다.

| 상태 | 축의 시작 |
|---|---|
| 준비중 | 첫 큐. 전체가 그려진다 |
| 진행중 | 현재 큐. 지난 큐는 접힘 헤더 |
| 종료 | 첫 큐. 전체가 그려진다 |

레일은 항상 전체 큐를 그린다 — 지난 구간이 사라지면 전체 조망이라는 목적이 없어진다.

## 폴링과 카운트다운

| | 주기 | 출처 |
|---|---|---|
| 폴링 | 2초 | `GET /cuesheets/{id}` |
| 카운트다운 | 1초 | 로컬 시계 |

카운트다운은 폴링 응답이 아니라 로컬 시계로 센다. 응답이 끊겨도 숫자가 멈추지 않는다 — 지하 행사장 회선 대응이 별도 오프라인 처리 없이 된다.

응답이 오면 화면 전체를 다시 그린다. diff 없다.

폴링이 연속 3회 실패하면 상태 표시만 바꾼다. 화면은 마지막 응답 그대로 두고 카운트다운도 계속 센다 — 진행 중에 화면이 비면 담당자가 자기 순서를 놓친다.

## 상태별 화면

| 상태 | run | timeline |
|---|---|---|
| 준비중 | 시작 버튼(manager). 카운트다운 없음 | 전체 축 |
| 진행중 | 카운트다운 + 다음/되돌리기 | 현재 큐부터 |
| 종료 | 읽기 전용 배너 | 전체 축 |
| 큐 없음 | 빈 안내 | 진입 막음 |
| 담당 큐 없음 | P0에 "담당 순서 없음" | 전체 축은 그대로 |

`ended_at`이 찍힌 큐시트는 읽기 전용이다 — 편집·진행 조작을 전부 숨긴다.

## 권한

| 요소 | manager | viewer |
|---|---|---|
| 시작·다음·되돌리기·종료 | 보인다 | 숨긴다 |
| 자기 역할 todo 체크 | 가능 | 가능 |
| 다른 역할 todo 체크 | 가능 | 숨긴다 |

`me.can_advance`로 가른다. 화면에서 숨기는 것은 편의이고, 권한 판정은 서버가 한다.

### 동시 조작

`advance`·`rewind` 요청에 화면이 본 `expected_cue_id`를 담는다. 서버가 불일치를 멱등 처리하므로 클라이언트는 응답을 그대로 다시 그리면 된다 — 별도 충돌 표시를 만들지 않는다.

| 항목 | 이유 | 추가할 시점 |
|---|---|---|
| 레일 눈금 | 10px 옆에 눈금을 붙이면 본문을 더 내줘야 한다 | 90분급 행사를 다룰 때 |
| 레일 폭 확대 | 본문을 가리고 시선을 뺏는다 | - |
| 계획 대비 실제 2트랙 | 실제 진행 시각을 읽는 경로가 없다 | 도메인 이벤트로 리뷰 화면을 만들 때 |
| 타임라인에서 편집 | 편집은 큐 상세에서 한다 | - |
| 애니메이션 | 필터 전환 외 없다 | - |

## 남은 결정

1. **레일 탭이 구간 점프인가 큐 선택인가.** 지금 설계는 스크롤바 관습대로 점프다. 큐 선택이 더 잦은 동작이면 바꾼다.
2. **`delay_sec`가 양수만 온다.** 앞당겨진 상태를 화면이 표현할 수 없다. 표현이 필요하면 서버 계산을 바꿔야 한다.
3. **지난 큐 접힘을 펼칠 수 있게 할 것인가.** 펼치면 축의 기준점이 현재 큐에서 첫 큐로 옮겨간다.
